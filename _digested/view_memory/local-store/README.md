# local-store — 本地存储与检索

> 记忆自己落盘:SQLite、markdown、分层目录,不依赖外部服务。

## 定义

插件自带存储与检索,数据留在本地。判定标准:断网可用,数据路径可由用户检查。

## 立卡条件

≥300 星,或被 ≥5 个条目引用存储格式。

## 生长

本地存储的竞争力在**结构设计**(分层、审计、审批),不在星标。写卡时重点看:数据模型几层、写入是否可撤销、审计留痕在哪。这是最容易被"看起来都能做"掩盖差异的分支。
