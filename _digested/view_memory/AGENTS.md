## 分型(会随生态重划)

## 本册特有的判断线索

- **宿主背书是最大陷阱**:头部星标(OpenViking 29567、hindsight 20218)属于主项目。能用的替代证据是扩散数、npm 下载、"共用同一份配置/存储"。
- **收敛可能发生在服务端/配置层,不在插件接口层**。判断"是否成标准"要问:衍生者接的是哪一层?共用配置的算标准,只抄 UI 的只是参照物。
- **隐私先于能力**:头部两个都依赖外部服务,需要先确认数据存哪(hindsight 默认 Cloud)。
