## 生长

这是 memory 与 session 的**交界带**:与 session 类的压缩/回退条目容易重叠,归类时以"是否产生持久化"划线。上下文工程目前是标签增速前排(+285),值得盯。

**源码读完后,"固定边界"要按机制理解,不是按字面**:dsh-auto-memory 的动态记忆与唤回尾注走 `ctx.systemPrompt.context()` 投影成 **user 消息**、只在文本变化时追加到历史尾部;system prompt 里只放一段常量纪律,所以前缀不动。到水位后它不是裁剪历史,而是**建新会话 + 投 18 000 字符三段式交接材料**;技能固化会把 `SKILL.md` 导进 `<dshHome>/skills`,与 DSH skill 系统共用目录。

**边界要写清**:它同时写用户级、项目级、日志三份 Markdown,严格说也新增长期存储。按"主要作用是改变当轮上下文"暂归本分支;若读者按"是否持久化"划线,应把它视为 local-store 与 context-shaping 的交界样本,而不是纯整形器。
