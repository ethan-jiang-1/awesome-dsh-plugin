# external-engine — 挂外部引擎

> 工作流逻辑在外面,插件是配置与桥接:经 MCP 挂载、按预设驱动。

## 定义

插件自身不含编排逻辑,把外部引擎/服务接进 DSH。判定标准:去掉外部引擎,插件退化为配置文件。

## 立卡条件

≥3 个第三方衍生,或被 ≥5 个条目点名。

> 本轮破例:两个已立卡样本的第三方提及都是 0;按"类内头部 + 形态样本"立卡,门槛未变。ouroboros 是纯配置,接得最薄;tongflow 有 1 039 行可抄,但执行仍在外部 Python 引擎。

## 生长

**本分支是"声量高、扩散零"的集中地**:ouroboros 类内星标第一却零衍生,原因是形态特殊(依赖外部引擎,他人复制不了)。写卡必须回答"影响力归谁"。

第二个样本把"薄"拆成两种:**ouroboros 的 DSH 面 0 行可抄,tongflow 的 DSH 面 1 039 行可抄但离开外部引擎即无用**。共同点是影响力应记在主项目名下——前者的星标属于一个支持 15 个 runtime 的引擎,后者属于一个影视生产工具;DSH 适配层都只是最外层。若某天出现第一个衍生,说明外部引擎开始被当作标准。
