## 本册特有的判断线索

**本册是"声量 × 扩散"两轴的校准地**:ouroboros 星标类内第一却零第三方提及。

判断顺序:
1. 先看形态:纯配置包 / 挂 MCP / 本地实现——门槛决定可模仿性;
2. 再看扩散:零衍生是"依赖外部引擎别人复制不了",还是"根本没人跟随";
3. 最后给结论:真锚 / 明星 / 待观察。

`multi-agent` 是**最可能长出标准协议**的分支(任务板 = 共享状态接口),写卡时重点看:状态存哪、冲突怎么裁决、失败怎么收敛。
