# vertical-preset — 垂直工作台与预设

> 为某一类工作整包配置:小说写作、科研流程、特定产出物。

## 定义

插件交付的是"一套完整工作方式"而非能力零件:预设、工作台、流程模板。判定标准:装完即拥有一个面向特定产出的默认流程。

## 立卡条件

≥300 星,或出现第二个同垂类竞争实现。

## 生长

垂直预设的价值在**默认流程的质量**,星标通常不高但留存强。这类条目最容易被"通用编排"替代,写卡时要回答:它提供了什么通用组件给不了的东西。
