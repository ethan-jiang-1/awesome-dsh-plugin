# rewind-edit — 回退与编辑

> 回到过去的某一步:轮次回退、消息编辑。

## 定义

对既有会话做时间轴操作:轮次回退、消息改写。判定标准:操作后会话历史发生变化,但记忆存储不新增条目。

## 立卡条件

≥300 星,或与检查点/快照机制形成组合。

> 本轮破例:83/32 均未达 300;按"类内头部 + 两条互不相同的回退路线"立卡。门槛未变。

## 生长

**两条路线不可比**:turn-rewind 的状态权威在插件自己的 Change Ledger(全树快照),文件还原走自己的引擎、会话侧借宿主 fork;message-edit 的状态权威在宿主 session 日志(前缀 seed),版本树是 `parentSession` 的读时投影。前者能还原工作树,后者保留源历史且不删分支;两者的不可回退边界都在卡内列清(工具副作用、网络、进程、refs/index)。
