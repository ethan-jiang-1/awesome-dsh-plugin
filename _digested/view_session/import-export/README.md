# import-export — 会话导入导出

> 把会话搬进来、带出去:聊天记录导入、会话导出。

## 定义

会话数据的出入口:导入历史聊天、导出会话记录。判定标准:数据跨越 DSH 边界(进出),而不是在会话内编辑。
