# `view_session/` 工作规则

session 领域册。1024 条(第三大类)、本期新增 111、owners 931(单件 92%)。

> 写作顺序:新卡先写 `它替谁解决什么问题 / 适用面 / 业务价值`,再进八段;规范见 [`../_view/WRITING.md`](../_view/WRITING.md)。
>
> 通用纪律(底线、八段模板、默认门槛、七步同步)只在 [`../AGENTS.md`](../AGENTS.md);本文件只写**本册特有的判断线索**,不重复通则。

## 分型(会随生态重划)

`import-export`(导入导出)/ `rewind-edit`(回退与编辑)/ `interconnect`(会话互连)/ `compression`(上下文压缩)。

## 本册特有的判断线索

**供给第三大、沉淀最弱**:1024 条对 83 星头部、无协议级复用(有 fork/提及,但没有被复用的协议面)。这个缺口本身是结论——只能说"没有公认实现",不能推断"没人用"。

**收敛信号优先级**:出现第二个实现同一件事的插件 → 看它们是否互相提及 → 若一方开始被第三方点名,标准可能成形。届时按默认门槛立卡。

## 刷新

数字随 `census.py`/`delta.py`;每轮检查是否出现达到立卡条件的条目。
