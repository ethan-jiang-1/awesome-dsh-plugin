# `view_session/` 工作规则

session 领域册。914 条(第三大类)、本期新增 352、owners 829(单件 92%)。

> 通用纪律(底线、八段模板、默认门槛、七步同步)只在 [`../AGENTS.md`](../AGENTS.md);本文件只写**本册特有的判断线索**,不重复通则。

## 分型(会随生态重划)

`import-export`(导入导出)/ `rewind-edit`(回退与编辑)/ `interconnect`(会话互连)。

## 本册特有的判断线索

**供给第三大、沉淀最弱**:914 条对 83 星头部、零衍生。这个缺口本身是结论——只能说"没有公认实现",不能推断"没人用"。

**收敛信号优先级**:出现第二个实现同一件事的插件 → 看它们是否互相提及 → 若一方开始被第三方点名,标准可能成形。届时按默认门槛立卡。

## 刷新

数字随 `census.py`/`delta.py`;每轮检查是否出现达到立卡条件的条目。
