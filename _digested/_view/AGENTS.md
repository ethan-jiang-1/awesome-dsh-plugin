# `_view/` 工作规则

三块板是**对外第一屏**:读者只读这里就要能回答 ①什么冒出来了 ②哪里热闹 ③热闹领域里谁说了算。通用纪律(底线、覆盖式重建、⚠ 标注)在 [`../AGENTS.md`](../AGENTS.md),这里只写本目录的页面契约。

## 页面契约

| 页 | 回答 | 必须有的字段 |
|----|------|--------------|
| `README.md` | 入口:三块板索引 + 立册门槛 + 册内结构 | 数据截止、复现命令、⚠ 数据边界 |
| `01-emerging.md` | 新 owner 榜(本期首见、≥2 条)、标签增长 Top | 区间、净增、复现命令 |
| `02-heat-map.md` | 23 类热度表(新增/删除/占比漂移/单件占比) | 真/假热闹的判据说明 |
| `03-anchors.md` | 锚的两轴表 + 全类目锚清单 | 声量 ⚠、扩散数、单卡链接 |

每页顶部必须有:**本期区间**(old→new 短 hash)、**数据截止**、**复现命令**。

## 重建步骤

1. `python3 ../ecosystem/census.py` — 全量分布与标签。
2. `python3 ../ecosystem/delta.py <old-ref> <new-ref>` — 两期差异:新增/删除、类目热度、锚候选、模仿信号(③b)、标签增长(①b)。
3. 按上表**整页重写** `01/02/03`;`README.md` 只在立册或规则变化时改。
4. 领域册的快照数字同步刷新(见各册 `AGENTS.md`)。

## 本板特有

- **锚不是星标榜**:`03-anchors.md` 先按扩散(第三方提及)排,再给星标视图——这是本板最容易写错的地方。
- 新增领域册时,在本目录 `README.md` 的册表加一行,并给该册建 `AGENTS.md`;子分类只建 `README.md`。
