# `_view/` 工作规则

三块板是**对外第一屏**:读者只读这里就要能回答 ①什么冒出来了 ②哪里热闹 ③热闹领域里谁说了算。上游纪律在 [`../AGENTS.md`](../AGENTS.md),这里只写本目录特有的事。

## 页面契约

| 页 | 回答 | 必须有的字段 |
|----|------|--------------|
| `README.md` | 入口:三块板索引 + 立册规则 + 册内约定 | 数据截止、复现命令、⚠ 数据边界 |
| `01-emerging.md` | 新 owner 榜(本期首见、≥2 条)、标签增长 Top | 区间、净增、复现命令 |
| `02-heat-map.md` | 23 类热度表(新增/删除/占比漂移/单件占比) | 真/假热闹的判据说明 |
| `03-anchors.md` | 锚的两轴表 + 全类目锚清单 | 声量⚠、扩散数、单卡链接 |

每页顶部必须有:**本期区间**(old→new 短 hash)、**数据截止**、**复现命令**。

## 重建步骤

1. `python3 ../ecosystem/census.py` — 拿全量分布与标签。
2. `python3 ../ecosystem/delta.py <old-ref> <new-ref>` — 拿 ①新增/删除 ②类目热度 ③锚候选 ④模仿信号(③b) ⑤标签增长。
3. 按上表**整页重写** `01/02/03`;`README.md` 只在立册/规则变化时改。
4. 领域册的快照数字同步刷新(见各册 `AGENTS.md`)。

## 硬规则

- **零原创**:正文数字必须能在上面两条命令的输出里找到出处;归纳性判断可以写,但要标成判断(如「判读」「为什么不」)。
- **覆盖式**:不写"上期我们说过…",历史归 `_change_log/`。
- **⚠ 必带**:星标/下载一律标注为 2026-08-19 历史采样;新增头部为空要说"采样缺口"。
- **锚不是星标榜**:`03-anchors.md` 先按扩散(第三方提及)排,再给星标视图;两轴都高才是真锚。
- 新增领域册时在本目录 `README.md` 的册表加一行,并给该册建 `AGENTS.md`。
