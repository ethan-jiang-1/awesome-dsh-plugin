## 这个生态是什么

DSH = **DeepSeek Harness**(`deepseek-ai/deepseek-harness`,见根 README.md:7-9):DeepSeek 官方开源的 agent harness,"一切皆插件"——模型、工具、沙箱、会话存储、UI、连 agent loop 本身都是插件位。本仓库是它的社区插件目录(awesome list),收录以 `dsh plugin add` 安装、带 `dsh.bundle` 清单的插件。

所以读这 4489 个条目的正确姿势不是"看一个 awesome 列表",而是审视**一个开源 agent 框架的第三方生态在约 59 天内形成的结构**:收录类别、作者分布、描述特征及每个插件的能力披露。

## 方法与精度声明

- 统计脚本 [`census.py`](census.py) 仅用标准库:手写容错 YAML 子集解析 + 单趟 `git log --diff-filter=A` 取首录日期 + ⑧ 节新队列漂移。重跑方式:`python3 _digested/ecosystem/census.py`。
- **新鲜下载/星标不走仓库边车**(边车冻结,见 [`_method/00-index`](../_method/00-index.md)):趋势数字来自自采管线 [`fresh_probe.py`](fresh_probe.py),方法与**七个坑**见 [`_method/01-fresh-probe`](../_method/01-fresh-probe.md)。
- 技术标签是描述文本的正则判定,**有已知精度边界**(详见 [02](02-tech-landscape.md) 文末方法注记:如「本地推理」曾因匹配『离线』虚高到 44,现 35;「图像生成」曾因『绘图/画图/海报』等泛匹配报 361,收紧后 57)。引用具体标签数字时以最新一次 census 输出为准。
- 当前 173 个条目无法定位首录日期(早期批量导入先于 added-dates 基线),时间统计基于其余 4316 条。
- 解读性结论(场景/类别分组)是分析者归纳,不是注册表官方口径;分类计数可按 census 复核。
- **0002 起的一条口径纪律**:`data/capabilities.json` 的"能力"是**静态扫描**结果(读安装产物,不执行、不联网、不判意图),它回答"这个包会碰什么",**不回答"它是否安全"**;未扫到的条目渲染为「未检出」,不可读作"干净"。
