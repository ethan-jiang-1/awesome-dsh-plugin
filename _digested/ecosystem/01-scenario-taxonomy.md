## 场景重组:22 类 → 十个场景带

把官方货架重聚,生态的真实结构是:

| 场景带 | 构成 | 合计 | 一句话 |
|--------|------|-----:|--------|
| 界面与外观 | ui 358 + theme 88 + fun 83 | **529 (23%)** | 给聊天窗做壳:侧栏/桌宠/皮肤/动效 |
| Agent 能力扩展 | tools 295 + skill 92 | 387 (17%) | 给 agent 添加手和技能包 |
| 开发者工作流 | dev 193 + git 54 | 247 (11%) | 把 harness 变成 IDE/DevOps 工位 |
| 会话·记忆·上下文 | session 156 + memory 112 | 268 (12%) | 让 agent 记得住、接得上 |
| 成本·模型控制 | usage 124 + model 75 | 199 (9%) | 盯钱包、换大脑:余额/峰谷计价/路由中转 |
| 多模态外挂 | vision 83 + voice 36 | 119 (5%) | 给纯文本底座补眼睛耳朵(tag 层还有重叠,见 02) |

| 流程自动化 | workflow 131 | 131 (6%) | 长任务编排、多 agent 协作 |

**两大阵营**一眼可见:**做壳的**(界面+外观+娱乐 ≈ 23%)和**做增强的**(工具+会话记忆+流程+多模态 …)规模相当。前者的繁荣解释了为什么 theme 类能单独成类并直通 dsh-market。

## 几个跨类的真实场景(crosstab 与抽样佐证)

- **usage = 花钱看板**:124 条里 118 条命中成本标签,典型如 `02Muller25/dsh-api-balance`(输入框下实时余额)、`moon09300731/dsh-peak-cost-mode`(DeepSeek 高峰计价时段 09:00–12:00/14:00–18:00 自动切省 token 模式)、`Young4ever33/dsh-token-attention`(按日/周/月四桶计费统计)。**DeepSeek 按时段浮动计价直接催生了一个品类**。
- **安全是横切需求而非一类事**:安全标签命中 299 条,散布在 security(58)、notify(47)、tools(43)、dev(27)…——审批门禁、密钥托管、脱敏出现在所有场景带;`slywalker2006/dsh-passwords` 甚至用安全组件把 harness 改造成"服务器级多租户平台"(自动 HTTPS + 子用户配额)。
- **notify 的后半段是远程审批**:推送 × 安全共现 28 次——把审批请求推到微信/QQ 再放行,是 IM 集成的第一动机。
- **monorepo 拆包habit**:229 条来自 162 个仓,大户 `damonkoy/dsh-web-ui` 单仓拆 12 个子包条目收录。
