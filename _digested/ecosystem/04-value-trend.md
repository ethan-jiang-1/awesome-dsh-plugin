## 6. 优秀插件的共同特征(定性归纳;样本来自 0002,未在 0003 重抽)

1. **补纯文本底座的感官/证据链**:modlens、modsearch——输入图片/搜索 → 输出**结构化 JSON 证据**,不是"帮你看一眼"而是"给 agent 可核验的输入"。
2. **把 DSH 变成工作台/驾驶舱**:better-sidebar、dsh-web 全家、dsh-TUI、dsh-tui-pi——胜在"常驻可视 + 零配置";dsh-tui-pi 特意强调"纯 cordis 插件,不 fork 不 patch 上游",**尊重插件边界是头部自觉**。
3. **历史样本中,成本可见性是显著产品主题**:dsh-context、dsh-cost-meter、Balance-Whale——峰谷计价感知与 DeepSeek 使用场景相关;描述命中成本标签当前为 398,但本轮不做因果判断。
4. **可及性 = 远程 + IM 一体两面**:dsh-web/remote-web-ui、dsh-pocket、dsh-im。
5. **编排与记忆是"增强派"头部**:dsh-agent-teams、dsh-mnemon + 外部巨头(memory 是巨头最爱的切入点)。
6. **信任与安全获得静态披露基础设施**:dsh-vault 曾在 09-12 历史下载快照中出现;能力扫描快照为 2026-09-24,与当前名单 URL 对齐覆盖 3826/4489。该覆盖并非新扫描,不能更新当前安全或转化结论。
7. **分发轨道本身**:dsh-market 曾以 38.4 万下载居第一——是 2026-09-12 下载快照中的高值,不代表当前下载排名。

历史样本中 skill 33%、wsl 0% 转化(2026-09-12 队列)曾提示环境特定插件与纯 prompt 包可能存在采用门槛;不可外推到当前。旧能力扫描在当前名单 URL 对齐子集中有 486 条未检出能力,这是静态扫描结果,不能理解为无风险或实际未使用。
