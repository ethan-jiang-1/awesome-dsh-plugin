## 2. 价值定位:极端头部,且头部是"一家人"

- 下载 ≥1 万的仅 **56 条(1.7%)**,占下载总量 **55%**;Top10 占 37%。
- **dsh-web 单仓(`zhu1090093659/dsh-web`,catalog 时 7131★、fresh_probe 复测 7422★,6 个子包条目,08-27/28 入库)合计 96 万下载 = 全体生态的 18%**。本次观察窗内最大的单一事件:一个 monorepo 十天吃掉生态五分之一的下载量,且 download/stars 双榜登顶。
- 新入库条目(08-26 后)贡献 32% 的下载量——新东西并非无人问津,**局部机会在持续出现**。
- star 榜:外部巨头继续流入且涨幅惊人(archify 14283→53656、OpenViking 29567→35988、hindsight 20218→23210(09-12 复测 23482)),**新增腾讯 WeKnora(21766★)**;原生头部(better-sidebar 3421、modlens 3913、dsh-TUI 2882)与下载榜重合,是真使用。

## 3. 增量榜(velocity):钱花在哪

08-25 → 09-07 全体下载 205.7 万 → 532.1 万(**+159%/12 天**)。增量下载的类目分布:ui 21.4%、remote 9.5%、git 8.4%、skill 7.2%、market 6.5%——但 remote/git/skill 的高位几乎全是 dsh-web 一个仓贡献的;剔除它后,**真实需求增量集中在:ui(壳)、tools、usage(成本)、workflow(编排)、memory(记忆)**。

除 dsh-web 外的增速冠军:dsh-univer-office(办公套件,+64k)、modlens(+49k)、dsh-context(上下文仪表盘,+48k)、dsh-cost-meter(+30k)、dsh-agent-teams(+30k)、dsh-im(+24k)、dsh-vault(本地密码保险库,4 天 26k)。

## 5. 转化率:哪类插件更容易被真正下载

新入库队列 dl≥100 转化率:voice 80% > git 64% > theme 63% > notify 60% > workflow/remote/model ≈59%…**skill 33%、wsl 0%(30 条全哑)**。含义:skill/wsl 是"做了没人用"的高发区;工作流、模型接入、远程触达是新供给里转化最好的赛道。

## 6. 优秀插件的共同特征(定性归纳,Top30 + 崛起者抽样)

1. **补纯文本底座的感官/证据链**:modlens、modsearch——同一个模式:输入图片/搜索 → 输出**结构化 JSON 证据**(OCR/版面/引用),不是"帮你看一眼"而是"给 agent 可核验的输入"。
2. **把 DSH 变成工作台/驾驶舱**:better-sidebar(侧栏+终端+Git+子代理)、dsh-web 全家、dsh-TUI、dsh-tui-pi——胜在"常驻可视 + 零配置";dsh-tui-pi 特意强调"纯 cordis 插件,不 fork 不 patch 上游",**尊重插件边界是头部自觉**。
3. **成本可见性是中国市场刚需**:dsh-context、dsh-cost-meter、Balance-Whale——峰谷计价感知(倒计时到费率切换)是 DeepSeek 定价机制的直接产物。
4. **可及性 = 远程 + IM 一体两面**:dsh-web/remote-web-ui(扫码配对+令牌门控+SSE)、dsh-pocket(cloudflared 隧道)、dsh-im(9 渠道聚合)。
5. **编排与记忆是"增强派"头部**:dsh-agent-teams(59k 下载)、dsh-mnemon(跨 Agent 本地优先记忆)+ 外部巨头(memory 是巨头最爱的切入点)。
6. **信任与安全开始转化**:dsh-vault(本地加密凭据库,TOTP/轮换/只读模式)零星标 4 天 26k 下载——安全类第一次出现在下载榜前列。
7. **分发轨道本身**:dsh-market 38.4 万下载居第一——**市场即头部插件**,生态自我强化。

反面特征(skill 33%、wsl 0% 转化):微工具单件(omdsh-dev 系列)、环境特定(wsl)、纯 prompt 包——**"能装"不等于"被用"**;无 UI 存在感、无持续会话价值的东西沉底最快。
