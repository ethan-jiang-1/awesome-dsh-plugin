## 6. 优秀插件的共同特征(定性归纳;0002 复核 + 新增)

1. **补纯文本底座的感官/证据链**:modlens、modsearch——输入图片/搜索 → 输出**结构化 JSON 证据**,不是"帮你看一眼"而是"给 agent 可核验的输入"。
2. **把 DSH 变成工作台/驾驶舱**:better-sidebar、dsh-web 全家、dsh-TUI、dsh-tui-pi——胜在"常驻可视 + 零配置";dsh-tui-pi 特意强调"纯 cordis 插件,不 fork 不 patch 上游",**尊重插件边界是头部自觉**。
3. **成本可见性是中国市场刚需**:dsh-context、dsh-cost-meter、Balance-Whale——峰谷计价感知是 DeepSeek 定价机制的直接产物(0002:成本标签从 317 涨到 392)。
4. **可及性 = 远程 + IM 一体两面**:dsh-web/remote-web-ui、dsh-pocket、dsh-im。
5. **编排与记忆是"增强派"头部**:dsh-agent-teams、dsh-mnemon + 外部巨头(memory 是巨头最爱的切入点)。
6. **信任与安全开始转化,并在 0002 拿到了基础设施**:dsh-vault 曾零星标 4 天 26k 下载;**0002 新增能力披露**(#401)把这件"用户自担风险"的事第一次变成可逐条核对的事实(十种能力 + redLines,3844/4392 覆盖)。
7. **分发轨道本身**:dsh-market 曾以 38.4 万下载居第一——**市场即头部插件**,生态自我强化。

反面特征(skill 33%、wsl 0% 转化):微工具单件、环境特定(wsl)、纯 prompt 包——**"能装"不等于"被用"**。**0002 新增一条反面特征的量化版**:487 条被扫出"零能力"(纯静态/纯提示词),它们最接近"装了也不知道做了什么"的那一端。
