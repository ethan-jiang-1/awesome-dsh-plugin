## 技术含义解读

**1. "给纯文本底座补感官"仍是最大技术主题,但增速已过峰。**
视觉/语音全靠外挂桥(贴图 → VLM 转文字 → 回填文本模型)。图像理解 63 + OCR 77 + ASR 31 + TTS 41 + 图像生成 49 + 视频 80,合计约 341 次命中(多标互有重叠)。但新队列里 vision 占比 −1.9pp(见 01 §表)——第一波补感官红利吃完,现在活下来的是"结构化 JSON 证据"模式(见 04 §6)。

**2. 模型阵营:官方母公司门内,Claude/OpenAI 仍是第二梯队,但国产阵容在长。**
DeepSeek 187(部分自指)→ Claude 117 > OpenAI 91 > GLM 35 ≈ Kimi 32 > Gemini 29 ≈ Qwen 27。更结构性的信号是**模型聚合/路由 235 条**:OpenRouter / one-api / new-api / LiteLLM 中转几乎是标准件——"换大脑"能力被普遍视为 harness 应有之义。

**3. MCP 已是主要扩展协议:162 条**,把外部 MCP server 注册为原生工具、或反向暴露 DSH 能力为 MCP 服务。

**4. 成本工程是中国特色品类,且在加速。**
用量/成本监控 317 条,最大共现对就是 `DeepSeek × 用量/成本监控 (97)`——峰谷计价感知、余额显示、token 统计、费用倒计时。五日增量下载里 usage 类 +5.4 万(见 04 §7),定价机制持续塑造插件形态。

**5. 安全/权限以绝对第一命中 465 条且横切一切**(sandbox/审批/密钥/脱敏),见 [01](01-scenario-taxonomy.md) crosstab;桌面集成 284 条(wsl 类贡献 26)说明大家默认它跑在自己电脑上。

**6. 高频共现的几组"功能簇"**(0001 复核后秩序微调):
- `DeepSeek×用量 (97)`、`任务×安全 (61)`、`主题×文档 (53)`、`安全×桌面 (46)`、`路由×用量 (41)` — 中转和省钱是一体两面;
- `RAG×上下文 (35)` — 记忆管线天然要管 token 预算;
- `桌面×浏览器 (35)`、`任务×桌面 (37)` — 办公自动化即"替我操作+替我确认"。

- 标签由约 34 组正则在合并后的 en+zh 描述上判定,**接受多标**,故各标签之和远大于条目数;
