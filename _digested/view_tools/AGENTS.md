# `view_tools/` 工作规则

tools 领域册。1639 条(第二大类)、本期新增 586、owners 1254(单件 87%,多样性最好)。

> 通用纪律(底线、八段模板、默认门槛、七步同步)只在 [`../AGENTS.md`](../AGENTS.md);本文件只写**本册特有的判断线索**,不重复通则。

## 分型(会随生态重划)

`single-purpose`(单点工具)/ `toolchain-meta`(工具链元层)/ `integration-bridge`(集成桥)。

## 本册特有的判断线索

**第二大类却没有千星锚**:477 星之后直接掉到 147,与"杂类收纳"定位一致——什么都能塞,所以没有统一叙事。

两种突出要分开写:**单点工具**(解决一个问题,星标是天花板)与**工具链元层**(不完成业务但被其他工具依赖)。后者更可能是潜在锚,优先观察依赖数而不是星标。

## 刷新
