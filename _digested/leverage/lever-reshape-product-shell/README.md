# lever-reshape-product-shell · 自带宿主：它自己就是那个产品

> **标语**:*If you replace the surface, you own the product.* —— 换掉表层，首启、分发、降级就没人替你回答。
> **分工**:本 lever 只收**自带宿主**的样本；能 `dsh plugin --profile <任意> add` 装进别人 profile 的客人在 [`lever-reshape-product-plugin`](../lever-reshape-product-plugin/README.md)。**先分 lever，再看编号。**

> **范围**:兼容 **DSH `0.2.x`**；`0.1.x` 的冻结 fork 只作反例。

## 1. 为什么要单开一个 lever

**因为改第 2 层，5/6/7 层就归你。** 这是本域的门（[`0-领域模型`](../lever-reshape-product-plugin/0-领域模型-七层与命名约定.md)）里那条**规律 A**：

| 层 | 名字 | 插件侧 | 宿主侧 |
|---|---|---|---|
| 1 | 运行时 | 上游 | 上游 |
| 2 | **表层** | 在别人的界面上加东西 | **换掉它**（终端壳 / 桌面框 / 另一块屏） |
| 3 | 槽位 | 可加 | 自己定 |
| 4 | 身份 | 可加 | 自己定 |
| 5 | 默认值 | 宿主给 | **自己给**（规律 A） |
| 6 | 首启 | 宿主给 | **自己给**：第一次打开看到什么 |
| 7 | 分发 | 宿主给 | **自己给**：从哪装、怎么更新、坏了怎么回 |

**一句话**：插件侧抄的是**接缝**，宿主侧抄的是**整机**。混在一起读，最容易把 `1-终端即产品` 当成"又一个工作台"——它不是，它把 DSH 变成了另一个应用。

## 2. 入桶判据

命中**一条**就进这一桶；一条都不中就留在 [`plugin` 侧](../lever-reshape-product-plugin/README.md)。

| # | 判据 | 为什么它决定归属 |
|---|---|---|
| H1 | **换掉表层**（第 2 层）：终端的壳、桌面的框、另一块屏的入口 | 换了"应用"，就没人替你回答"第一次打开什么样"（规律 A） |
| H2 | **不是 profile 里的客人**：全局 CLI、独立安装器、forked 宿主 | `dsh plugin add` 装不进去，或装进去也没意义 |
| H3 | **自带一条完整的装-坏-回链路**：更新器 / 卸载器 / 救生页 / 安装包 | 这条链一旦归它，它就已经是产品而不是零件 |

> **三张边界样本为什么不在这一桶**：`1-厚工作台` 没换表层（还是 `web` profile）、`5-分发与救生页` 的救生页是替宿主兜底、`6-多端与远程` 把 `dsh web` 当回环上游——它们都是**厚客人**。逐条理由见 [plugin 侧 §1.1](../lever-reshape-product-plugin/README.md)。

## 4. 宿主侧必抄 5 条

**前 4 条来自正面样本，第 5 条是反面样本的唯一正确用法。** 这五条只在"你换了表层"时成立——插件侧抄它们会抄成过度设计。

1. **每档能力一条"退化为 Y"**：终端不支持通知 → 响铃；没有图片协议 → 纯文本；最差档必须**不静默**（响铃 / 纯文本 / 不激活）。
2. **输入解析的 hold 窗口不被延长，超界原样重放**：别为了等一个可能的组合键，把用户已经敲下的字符吞掉。
3. **恢复不确定就报错退出**，不要猜着往下恢复——猜错比退出更难收拾。
4. **更新只看退出码**，不看输出文本；首启四步向导要能在**没有网络**时走完。
5. **peer 上界 = 死亡日期**：只写下界 + CI 矩阵，或换接缝（换挂载点 / 换协议）；真要 fork，就承认自己是分家，别假装还能装回上游。

## 6. 与 plugin 侧的取舍

| | [`plugin` 侧](../lever-reshape-product-plugin/README.md) | 本 lever |
|---|---|---|
| 你得到 | 装进任何产品的**零件**，宿主替你兜首启/分发/降级 | **整个产品**，包括第一次打开、装坏了怎么回 |
| 你付出 | 受上游接缝约束，能改的只有槽位与内容 | 首启、分发、降级、救生页**全归你**（规律 A） |
| 抄错的样子 | 硬依赖一个不存在的服务 → 白屏 | 换了表层没补 5/6/7 → 首启即崩，用户归因给整个产品 |

## 7. 边界

**收**：换表层 / 自带宿主 / 自带装-坏-回链路，且有可复核的影响力证据。

**不收**：能 `dsh plugin add` 装进别人 profile 的插件（去 [`plugin` 侧](../lever-reshape-product-plugin/README.md)）；只加能力的工具类插件。

**共享文件只读**：`00-map.md`、`horizon.md`、`leverage/README.md`、`data/` 由别的会话维护，本 lever 只调用、不写。
