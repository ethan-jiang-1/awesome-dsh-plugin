# replace-shell — 换壳

> 替换 DSH 的完整界面:把 web UI 换成终端全屏 TUI 或其他形态。

## 定义

插件接管整个呈现层,DSH 变成另一个界面。判定标准:卸载后界面消失,不是"少一块"而是"换一套"。

## 立卡条件

≥1000 星,或成为某类用户的事实入口。

## 生长

换壳是一条**独立路线**,与 enhance-shell 不可比:换壳的代价是接管全部渲染与交互(更新跟随宿主 API 断裂),收益是完全控制体验。两条路线的优劣判断要分开写,不要混在一张表里排名。
