# inline-genui — 内联生成式 UI

> 由模型在回复流里渲染交互组件:HTML 卡片、图表、表单、Canvas 应用。

## 定义

输出侧扩展:模型生成的不只是文本,而是可交互的 UI 片段。判定标准:组件出现在聊天流内,不是固定位置的侧栏或页面。

## 立卡条件

≥800 星,或被 ≥5 个条目引用为渲染宿主。

## 生长

这是**最像"新范式"的分支**:如果模型生成的 UI 成为主流,生成协议与安全边界(渲染任意 HTML 的风险)会成为生态级问题。写卡时必须回答"渲染在哪一层、沙箱边界在哪"。
