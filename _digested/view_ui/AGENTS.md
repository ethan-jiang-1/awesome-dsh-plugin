# `view_ui/` 工作规则

ui 领域册。全表最大类(2351 条,20.0%),新作者的第一落点。

> 通用纪律(底线、八段模板、默认门槛、七步同步)只在 [`../AGENTS.md`](../AGENTS.md);本文件只写**本册特有的判断线索**,不重复通则。

## 分型(会随生态重划)

`enhance-shell`(增强现有壳)/ `replace-shell`(换壳)/ `inline-genui`(内联生成式 UI)。

**判断路线先于写卡**:同一个插件是"加一块"、"换一套"还是"渲染新东西",决定它的代价不可比——这个判断放在子分类 README,不进单卡。

## 本册特有的判断线索

- 类内头部断层明显(2216 / 2009 → 394 → 224),中部空心;新卡优先看 2000+ 星或高扩散者,不按星标流水账列。
- 新作者大量以 ui 为第一落点:回看 `_view/01-emerging` 的新 owner 榜,若同一作者的条目开始成组出现,是苗子信号。
- "增强壳"类要顺带看**权限边界**:面板能力往往等于宿主机同权限(见 enhance-shell 的 ⚠)。

## 刷新

册内数字随 `census.py`/`delta.py`;单卡不随每轮重写,只在被分析插件有新提交或扩散数显著变化时复核。
