## 输入 protocol 与 degradation

- `[SRC]` Win32 record 最大 64 bytes、首捕获起 1000 ms；expired prefix 通过 tokenizer reset 丢弃。terminal-response prefix 独立使用 64 bytes/1s，必须同时有 pending-query response-type evidence 才 claim，期限/授权消失也会丢掉 held protocol bytes。[bounds](https://github.com/ccch1mneyyy/dsh-TUI/blob/83fcf892d49c4f4e5b05fab2936fac2241bad579/src/ink/parse-keypress.ts#L40-L64) [record gate/expiry](https://github.com/ccch1mneyyy/dsh-TUI/blob/83fcf892d49c4f4e5b05fab2936fac2241bad579/src/ink/parse-keypress.ts#L1842-L1980) [reply evidence](https://github.com/ccch1mneyyy/dsh-TUI/blob/83fcf892d49c4f4e5b05fab2936fac2241bad579/src/ink/parse-keypress.ts#L1853-L1871)
- `[SRC]` 只有被 evidence-gate claim 的 SGR mouse head 会在 timeout/overflow 以普通键 replay；非 gated/legacy path 的行为不同。因此卡片“任何解析 hold 超界都按序回放”的表述不成立。[gated release](https://github.com/ccch1mneyyy/dsh-TUI/blob/83fcf892d49c4f4e5b05fab2936fac2241bad579/src/ink/parse-keypress.ts#L2115-L2139) [head claim](https://github.com/ccch1mneyyy/dsh-TUI/blob/83fcf892d49c4f4e5b05fab2936fac2241bad579/src/ink/parse-keypress.ts#L2240-L2280)
- `[TEST]` Win32 verifier 对 fragment/flush split、1s/64B、ordinary text、conhost paste 和 CRLF folds 有大量确定性检查；CI 登记 `verify-win32-input` 与 `verify-paste-integrity`。它们不等价于在真实 PowerShell/ConPTY/SSH/tmux 上验证；同一测试也明确固定了残余歧义：ESC 宽限期内看起来像 Win32 record 的 literal 可能被当作协议 prefix hold。[fixture scope](https://github.com/ccch1mneyyy/dsh-TUI/blob/83fcf892d49c4f4e5b05fab2936fac2241bad579/scripts/verify-win32-input.tsx#L1-L30) [expiry/bounds](https://github.com/ccch1mneyyy/dsh-TUI/blob/83fcf892d49c4f4e5b05fab2936fac2241bad579/scripts/verify-win32-input.tsx#L780-L834) [ambiguous literal residual](https://github.com/ccch1mneyyy/dsh-TUI/blob/83fcf892d49c4f4e5b05fab2936fac2241bad579/scripts/verify-win32-input.tsx#L875-L890) [CI inventory](https://github.com/ccch1mneyyy/dsh-TUI/blob/83fcf892d49c4f4e5b05fab2936fac2241bad579/scripts/run-ci-group.mjs#L373-L398)

## Updater 与 owner lifecycle

- `[SRC]` updater timeout 默认 30 分钟且独立于输出活动。POSIX detached process group 是 kill ownership boundary：TERM 后默认 2s 再 KILL；等 child close，且树 cleanup 未确认时上层 update 明确禁止再跑 installer、清旧文件、修复或重启。[timeout](https://github.com/ccch1mneyyy/dsh-TUI/blob/83fcf892d49c4f4e5b05fab2936fac2241bad579/src/updateProcess.ts#L1-L12) [POSIX process group](https://github.com/ccch1mneyyy/dsh-TUI/blob/83fcf892d49c4f4e5b05fab2936fac2241bad579/src/updateProcess.ts#L36-L139) [no unsafe retry](https://github.com/ccch1mneyyy/dsh-TUI/blob/83fcf892d49c4f4e5b05fab2936fac2241bad579/src/update.ts#L1895-L1935)
- `[SRC]` Windows supervisor 用 native Job Object：子安装器以 `CREATE_SUSPENDED` 创建，借 `JOB_LIST` 在创建时原子进入 job、验证成员后才 Resume；job 设置 kill-on-close 且禁止 breakaway；cleanup 必须 drain 到 active=0，failure fail closed。[C# job setup/atomic assignment](https://github.com/ccch1mneyyy/dsh-TUI/blob/83fcf892d49c4f4e5b05fab2936fac2241bad579/assets/windows-installer.cs#L116-L270) [supervisor contract](https://github.com/ccch1mneyyy/dsh-TUI/blob/83fcf892d49c4f4e5b05fab2936fac2241bad579/src/windowsInstaller.ts#L1-L125)
- `[SRC]` `/update` 要求目标版本核验；若 cleanup 不明确或 profile 版本混合，不得 restart。更新完成通过既有 handoff resume 当前 session/backend。[update code](https://github.com/ccch1mneyyy/dsh-TUI/blob/83fcf892d49c4f4e5b05fab2936fac2241bad579/src/update.ts#L1895-L1978) [restart](https://github.com/ccch1mneyyy/dsh-TUI/blob/83fcf892d49c4f4e5b05fab2936fac2241bad579/src/update.ts#L2012-L2039)
