## 一、上游语义：profile = 有序 bundle 栈 + 用户 patch

来自本机 `@deepseek-ai/dsh` 包内 `README.md`：

| 原文 | 行 |
|---|---|
| `A profile directory holds a package.json (out-of-tree plugin dependencies plus the profile manifest dsh.profile with its ordered bundles list) and a cordis.patch.yml (the user's own patch layer).` | `README.md:37` |
| 组合顺序：`each bundle's patch in dsh.profile.bundles order` → 用户层 → `--patch` 叠加 → flag patches | `README.md:42` |
| `Bundles named in dsh.profile.bundles resolve from the dsh installation first (…), then from the profile's own node_modules, where pnpm installs out-of-tree plugins.` | `README.md:46` |
| `The desktop name is reserved for the Electron-owned profile, so the CLI rejects boot and config-dump requests for it.` | `README.md:20` |
| `dsh web` = Boot the Web profile；`dsh --profile <name>` = 启动 `$DSH_HOME/profiles/<name>` | `README.md:11,17` |

来自上游架构注记 [`2026-08-05-profile-plugin-bundles.md`](https://github.com/deepseek-ai/deepseek-harness/blob/25d959aa085865f9d889e3a663ce018669258207/.agents/notes/implemented/architecture/2026-08-05-profile-plugin-bundles.md)：

- **"Everything becomes a profile"**：TUI、provider pack 都做成**普通 npm 包**，可逐 profile 安装；
- **bundle 的判据**：npm 包声明 `"dsh": { "bundle": { "patch": "./cordis.patch.yml" } }`；
- **两种 manifest 键**：`dsh.profile`（profile 清单，含有序 `bundles`）与 `dsh.bundle`（bundle 身份）——一个 package.json 说明自己扮哪个角色；
- **组合是纯数据**：每个 bundle 的 patch 按 `dsh.profile.bundles` 顺序打在一个**空根**上，再叠用户层、`--patch`、flag patches，最终由一次 `applyEntryPatches` 完成——boot、flag 推导、`--dump-config` 走同一条路径；
- **解析双锚**：`dsh.profile.bundles` 里点名的包**先**从 dsh 安装里解析，**再**从 profile 的 `node_modules`；裸插件名走 profile 目录的 Node 父级查找 + `$DSH_HOME/profiles/node_modules` 的扁平兜底（每次启动自愈）。

**这条语义决定了"profile 即产品"的抄法**：产品不是改界面，是**发一个 bundle**（带 `dsh.bundle.patch`）+ 让用户把它加进 `dsh.profile.bundles`。首启、默认值、分发、迁移这些"层 5/6/7"的事，全都落在**你那个 patch 文件**与**你那个包**里。

## 五、2026-10-31 复核：patch 形态已关闭

**取数**：`https://raw.githubusercontent.com/zhu1090093659/dsh-web/main/package.json` 与 `.../packages/dsh-web-all/cordis.patch.yml`（2026-10-31）。

- 根 `package.json`：
  ```json
  "dsh": { "bundle": { "patch": "./packages/dsh-web-all/cordis.patch.yml" } }
  ```
  → **入口 bundle 只有 1 个**；子包由这个 patch 挂载。
- patch 文件（147 行）头三行：
  ```
  # AUTO-GENERATED by scripts/aggregate.mjs — do not edit
  # Rows are namespaced web-ui-* so the bundle can coexist with standalone installs.
  ```
- 全文 **25 条 `insert:`**，id 均为 `web-ui-*`；**不存在**指向 `@deepseek-ai/dsh-web-app` 行 id 的改写。
- 结论：**纯追加，不改宿主行**；兼容风险从"上游行号"转移到"slot / loader id 的命名与 25 个 insert 包的版本"。
