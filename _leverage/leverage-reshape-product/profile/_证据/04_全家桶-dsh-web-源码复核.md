## DSH 装载与启停行为

- **DSH UPSTREAM：** 已安装的官方 DSH CLI 包版本为 `@deepseek-ai/dsh@0.2.1-rc.3`（官方发行包 `package.json` 版本字段）。其 app-boot profile resolver 按 profile `dsh.profile.bundles` 顺序读取每个包的 `dsh.bundle.patch`，校验最低运行时后解析 bundle patch；不可解析/不兼容的**bundle**会被 `skippedBundles` 记录。随后合成 profile `cordis.patch.yml`；CLI Web profile 文档默认栈是官方 base + web-app。DSH sources: `@deepseek-ai/dsh/package.json:4`; `@deepseek-ai/dsh-app-boot/lib/index.js:995-1050`; `@deepseek-ai/dsh/lib/profile-boot-C14i-8IN.js:75-84`
- **DSH UPSTREAM：** 对同 id patch entry，官方 `applyEntryPatches()` 的 id map 用 `Map.set`，后续 patch 对已有 row 应用 overrides；profile boot 的顺序是 bundles、profile 自己的 patch、home-level patch、CLI `--patch`。所以聚合 layer 先提供包默认值，profile/home user layer 可以以 `disabled: false` 覆盖 bundle 的 `disabled: true`。Home patch 在 profile patch 之后，故 machine-wide layer 可再覆盖 profile-local 值。DSH sources: `@deepseek-ai/dsh-app-boot/lib/index.js:61-109`; `@deepseek-ai/dsh/lib/profile-boot-C14i-8IN.js:223-246`
- **TARGET SOURCE / DSH UPSTREAM：** `inactive` 不是“未安装包”：两个 family 包仍在 dependencies 并有 patch row，只是 generator 在 patch 尾部加 `disabled: true`，用户可由插件管理器逐行启用。官方 `reconcileProfilePlugins()` 将新加入的 bundle dependency 自动追加进 `dsh.profile.bundles`；成功的 add 即写入 profile bundle roster，remove 或 package 不再声明 bundle 时从 bundle list 移除。更新/安装该 aggregate 不代表所有 family 行都会生效，disabled/profile compatibility 仍决定 mount。[`renderPatch` inactive behavior](https://github.com/zhu1090093659/dsh-web/blob/88409fb958e4b97e7c179b9e50d26f5359627710/scripts/aggregate.mjs#L925-L968) DSH source: `@deepseek-ai/dsh-app-boot/lib/index.js:1160-1228`
- **TARGET DOC：** 仓库给出的常规安装入口为 `dsh plugin --profile web add @linxin666/dsh-web-all@latest` 或直接加 `github:zhu1090093659/dsh-web`，两者称作等效方式；不要同时安装，以免 entry id 冲突。安装后文档要求重启 `dsh web`，网页刷新不能载入新模块；卸载聚合包用 `dsh plugin --profile web remove @linxin666/dsh-web-all`，同样重启后回到纯净状态。[README 安装段](https://github.com/zhu1090093659/dsh-web/blob/88409fb958e4b97e7c179b9e50d26f5359627710/README.md#L203-L260) [README 验证/卸载/重启说明](https://github.com/zhu1090093659/dsh-web/blob/88409fb958e4b97e7c179b9e50d26f5359627710/README.md#L305-L355)

## What this establishes

**TARGET SOURCE, supported:** dsh-web is a version-coordinated family of installable plugins assembled by a declarative generator into a DSH profile bundle. Bundle identity is a profile dependency name with `dsh.bundle.patch`; patch row ids form a separate namespace and are deliberately distinct from standalone child ids. The aggregate package installs the family packages and assembles their actual plugin entry points, with selected rows disabled by default and user layers overriding defaults. New npm bundle dependencies become active in DSH profile metadata after a successful add; the user-facing repository instructs restart for the running Web process.

**Not established:** 本静态复核不证明仓库 README 的能力规模/性能/稳定性、GitHub root package add 在所有环境下都成功，也不把 CI 配置说成已通过。要作用户现场确认，应在单独 scratch DSH home/profile 核对 `dsh --profile web --dump-config`、installed manifest/lockfile 和真实启动日志；本次按只读范围未执行。
